📖 BookReader — installateur Windows

Livres audio avec voix neuronales (XTTS-v2) sur le GPU NVIDIA, entièrement hors ligne.

Deux façons de l'obtenir :
  • BookReader-Setup.zip : tout en un seul fichier. Décompressez-le, puis lancez BookReader-Setup.exe.
  • BookReader-Setup.exe + tous les BookReader-Setup-N.bin : à télécharger dans le même dossier, puis lancez le .exe.
Prérequis : Windows 64 bits, carte NVIDIA (GTX 9xx à RTX 50xx) avec un pilote récent (≈ 570 ou plus), environ 10 Go libres. L'installateur n'est pas signé : Windows SmartScreen peut afficher un avertissement (« Informations complémentaires » puis « Exécuter quand même »). Vérifiez les fichiers avec SHA256SUMS.txt (Get-FileHash -Algorithm SHA256 fichier).
